# Docx Guide

이 폴더는 백엔드 협업 문서와 페이지별 개발 지침을 모아둔 기준 문서 저장소다.

우선순위:
- `project-structure-guide.md`: 폴더 구조와 책임 분리 규칙
- `db.md`: 데이터베이스 확정 스키마 및 제약
- 페이지별 문서: `auth.md`, `emotion.md`, `constellation.md`, `reaction.md` 등

기존 계약 문서는 `/docs` 폴더도 함께 참고한다.
- `docs/api-contract.md`
- `docs/backend-handoff.md`

앞으로 리팩토링이나 기능 개발 시 아래 순서로 기준을 확인한다.
1. `project-structure-guide.md`
2. 관련 페이지 문서
3. `db.md`
4. `docs/api-contract.md`
